# React SPA SED

Фронтенд Фазы 5 (README п.6): статика собирается в `frontend/Dockerfile`, отдаётся через `proxy` (отдельного рантайм-сервиса нет).

## Железные правила

- UI — только по матрицам ролей README п.1: ОК — всё + полная карточка, владелец — свои задачи + урезанная карточка без ПДн, админы — всё + настройки, остальные — ничего.
- Логин — через `/auth` (LDAPS bind на стороне API); пароли и токены в localStorage не хранить.
- Создание ОК: предприятие → сотрудник → выбор бланка (`GET /requests/route/blanks`) → маршрут →
  печать; отметки владельца — только свои шаги, у шага видны все ответственные и прогресс отметок.
- Вкладки по ролям: «Заявки» всем; «Справочник» — ОК/руководитель ОК/admin; «Сопоставление» —
  admin; «Настройки» — admin/руководитель ОК. Лишних вкладок быть не должно.
- В админке настроек вкладка «Бланки» (только admin): карточка бланка (шапка `header_html` и подвал
  `footer_lines` с кнопками вставки плейсхолдеров) и собственные шаги бланка — название/текст, вид
  исполнителя (`executor_kind`: список согласующих / группа AD / руководитель), режим
  `parallel`/`sequential`, флаги `optional`/`require_comment`. Этапа справочника у шага бланка нет.
  Вкладка «Шаблоны» удалена (легаси), редактор писем — на вкладке «Письма». Текст шага и шапка
  правятся визуальным редактором (`rich-text.tsx`, TipTap), HTML доходит до печати. UI загрузки
  docx-шаблонов больше нет.
- Снятие шага бланка в форме заявки — по номеру шага (`dismissed_step_orders`), не по коду этапа;
  в `dismissed_stages` уходит только снятие этапов профиля/ручного маршрута.
- Форма заявки: `link_state=need_link` показываем кандидата AD и кнопку подтверждения связи;
  при блокировке маршрута — понятное действие (подтвердить/перейти в «Вручную»), не пустой экран.
- Админка настроек — только для `SED_ADMINS` (settings в БД, не в коде).
- Прогон UI — через MCP `playwright` в intranet; матрицы ролей проверять после каждой правки.

## Приемка правки

Матрицы ролей из п.1 зелёные (playwright), затронутые экраны работают, ПДн не светит владельцам.

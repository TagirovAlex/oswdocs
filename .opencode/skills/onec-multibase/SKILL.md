# 1С Multi-base (только чтение)

Базы 1С ЗУП опубликованы на 1С web-сервере (OData/HTTP). Запись запрещена.

## Железные правила

- Клиент `OneCClient(base_code)`: только GET карточки (`предприятие, таб.№, ФИО, подразделение, должность, вид занятости, дата приема, остаток отпуска`). Сервисная УЗ чтения — на каждую базу, реквизиты — в настройках (`ONEC_BASES_JSON`).
- сценарий: ОК выбирает предприятие из настроек → сотрудника из привязанной базы. Веерный опрос всех баз — только как fallback с таймаутом 5с на базу; одна упавшая база не блокирует остальные (circuit-breaker).
- Ключ `enterprise+base_code+tab_num` (таб. пересекаются). Флаг МОЛ — TODO, поле nullable + ручная правка ОК.
- Остаток отпуска/дата приема — только роли ОК, исполнителям и в бланк не отдавать.
- Снапшот `snapshot_1c` в заявке + кнопка «обновить»; протухший (>24 ч) помечать.

## Приемка правки

Новая база подключается только настройками без кода, контракт GET един для всех баз, падение одной базы покрыто тестом.

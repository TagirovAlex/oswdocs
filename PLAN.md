- Настройка — в settings (например `directory_page_size`, по умолчанию, например, 50), без хардкода.
- Серверная пагинация поиска из локальной таблицы `employees` (offset/limit, total) — контракт
  `GET /api/employees` дополнить `page`/`page_size`/`total` (не ломать текущий ответ).
- Фронт `directory.tsx`: постраничный вывод + селект размера страницы.

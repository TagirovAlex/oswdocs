### H. Работа с шаблонами (docx) — решение принято 2026-10-03
- Сейчас бланки бегунка — текст в settings `doc_templates` (тело DOCX рендерится docxtpl из строк +
  переменных `{{ fio }}` и т.д., см. TEMPLATES.md); `.docx` файлов в проекте нет, итоговый вид — голые
  абзацы без вёрстки.
- РЕШЕНО: рендерить НАСТОЯЩИЙ .docx-шаблон через docxtpl — файл есть источник шапки/строк/подвала,
  вёрстка (поля, шрифты, логотип, таблицы) живёт в файле, итог визуально идентичен шаблону.
  Редактирование — в Word; в панели администратора — импорт/скачивание/замена/предпросмотр
  (WYSIWYG-редактор НЕ делаем). Строки — таблица с `{%tr%}` по шагам маршрута. Хранение —
  `FILES_DIR/templates/`, в settings — только имя файла. Старые текстовые `body` — фолбэк (не ломать).

Бэкенд:
- `api/app/docs.py`: рендер из файла `DocxTemplate(path).render(context)` вместо синтеза
  `Document()` из текста (шапка/подвал/таблицы из файла); в контекст добавить `steps` (list
  {order, owner, status}) и `qr` (docxtpl `InlineImage` — картинка-заглушка в шаблоне подменяется
  сгенерированным QR, `_render_qr_png`); `sanitize_context` (ПДн) сохранить; текстовый рендер
  оставить фолбэком для элементов без файла.
- `api/app/settings_routes.py`: `DocTemplateItem` + необязательное поле `file` (имя файла);
  эндпоинты admin: импорт .docx (валидация: zip + `[Content_Types].xml` + `word/document.xml` +
  тест-рендер фиктивным контекстом), скачивание, удаление.
- Файлы — в `FILES_DIR/templates/` (права контейнера api/worker, по образцу attachments/backups).

Фронт (`frontend/src/admin-settings.tsx`):
- В редакторе бланков вместо textarea — «Загрузить .docx / Скачать / Заменить / Удалить» + кнопка
  «Предпросмотр» (рендер на тестовых данных → PDF существующим LibreOffice-путём).

Тесты:
- Валидация импорта (не-zip, не docx, битый шаблон), рендер из файла, фолбэк на текстовый `body`.

Приемка:
- Загрузка .docx с шапкой/таблицей `{%tr%}`/подвалом → печать даёт PDF с вёрсткой файла.
- Старые текстовые бланки продолжают печататься как раньше.
- ПДн-ограничения сохранены: в контекст — только поля из TEMPLATES.md + `steps` + `qr`.

НЕ ДЕЛАТЬ: склейка «шапка.docx + текст + подвал.docx» (XML-merge хрупкий); WYSIWYG-редактор в панели
(OnlyOffice / DOCX↔HTML — вне объёма).
